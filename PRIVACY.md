# Privacy

Satchel is a local command-line build tool. It does not collect telemetry or
send package contents to Parker Hancock or the Satchel project.

Satchel reads the package paths selected by the user and writes generated
artifacts inside that package or an explicitly selected output directory.
Optional host validation invokes locally installed host command-line tools;
those tools are governed by their respective providers' privacy policies.

Questions about this policy may be raised through the repository's GitHub
issue tracker. Security-sensitive reports should follow `SECURITY.md`.
